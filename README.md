# BiasGuard

Open-source evaluation and governance toolkit for AI decision systems.

## Current milestones

- Deterministic fairness metrics
- Structured Noul / Score / Choice evaluation layer
- TypeSafe System One adapter
- Deterministic policy routing
- Audit records and state hashing
- Calibration and threshold analysis
- Governance dashboard prototype

See `README_CLI.md`, `CALIBRATION_SCHEMA.md`, and `dashboard/README.md`.
